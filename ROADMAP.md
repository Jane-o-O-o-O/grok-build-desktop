# Roadmap

Short list of what to tackle next for Grok Build Desktop. Keep this to a few active items.

## Next

1. **Real terminal** — `node-pty` + xterm so interactive shells work (Ctrl+C, prompts, pagers).
2. **Side-task parity** — attachments and streaming patches like the main conversation.
3. **Files panel CRUD** — create / rename / delete workspace files from the explorer.

## Recently shipped

- Tool card / timeline / session chrome i18n
- Curated slash picker and honest README
- Thread tidy, toast severity, browser teardown
- Push/PR verify CI (`verify-desktop.yml`)
- Runtime setup + editable files + browser URL polish

## Cadence

Aim for a small patch release every 2–4 weeks (`v0.1.x`). Prefer shipping a few polished fixes over large unreleased branches.
